QuickKart is a modern e-commerce product browsing web application built using HTML, CSS (Tailwind CSS), and JavaScript, integrated with a Flask REST API for dynamic data handling.

The frontend delivers a responsive and visually rich UI with smooth animations, interactive product cards, and real-time product rendering. It fetches product data from a Flask backend using REST APIs and dynamically displays them in a structured grid layout.

Key features include:

🔗 Integration with Flask REST API (/products) for live data fetching

🎨 Modern UI with Tailwind CSS and custom animations

🛍️ Dynamic product rendering with images, pricing, and descriptions

⚡ Smooth hover effects, transitions, and loading states

📱 Fully responsive design for all screen sizes

This project demonstrates the integration of a frontend interface with a backend API, focusing on clean UI/UX, asynchronous data handling, and scalable web architecture.
